Outlook-Kalender verbinden

Termine erscheinen im Familienkalender und bleiben aktuell: Schulblick holt den Kalender jede Stunde neu. Geändert wird weiter in Outlook, hier sind die Termine nur zum Lesen.

Wo finde ich den Link?
  • Outlook im Web (outlook.com oder Microsoft 365): Zahnrad → Kalender → Freigegebene Kalender → „Kalender veröffentlichen“ → Kalender und „Kann alle Details anzeigen“ wählen → Veröffentlichen → den ICS-Link kopieren.
  • Firmenkalender: Bei vielen Firmen ist das Veröffentlichen gesperrt oder nicht erlaubt. Dann lieber die Datei-Variante unten nutzen und nur private Termine übernehmen.

Einmalig aus einer Datei übernehmen

Die Termine werden normale Familientermine, die ihr hier weiter bearbeiten könnt. Einfache Serien (täglich, wöchentlich, alle 2 Wochen, monatlich, jährlich) bleiben Serien; kompliziertere werden für die nächsten zwei Jahre als einzelne Termine übernommen. Lädst du dieselbe Datei noch einmal hoch, werden die Termine aktualisiert statt doppelt angelegt.

Wie bekomme ich die Datei?
  • Outlook am Windows-PC (klassisch): Kalender öffnen → Datei → Kalender speichern → „Weitere Optionen“ → Datumsbereich und „Alle Details“ wählen → als .ics speichern.
  • Neues Outlook / Outlook im Web: einen einzelnen Termin öffnen → „…“ → Herunterladen; für den ganzen Kalender besser oben „Outlook-Kalender verbinden“ nutzen.
  • Auch .ics-Dateien von Vereinen, Schulen oder Google funktionieren.
