Mit diesem Link zeigt der Kalender auf deinem Handy alle Termine, die du hier im Schulblick siehst: Familientermine, Klassenarbeiten, Ferien, Schultermine und Vertretungen. Er aktualisiert sich von selbst, meist stündlich (Google: bis zu einmal am Tag).

Im Kalender öffnen

Behandle den Link wie ein Passwort: Wer ihn kennt, sieht deine Termine.

So geht's

  • iPhone: „Im Kalender öffnen“ antippen und „Abonnieren“ bestätigen. Oder: Einstellungen → Kalender → Accounts → Account hinzufügen → Andere → Kalenderabo hinzufügen → Link einfügen.
  • Android / Google Kalender: Am Rechner calendar.google.com öffnen → links „Weitere Kalender“ → „Per URL“ → Link einfügen. Danach erscheint er auch auf dem Handy.
  • Outlook: Kalender → Kalender hinzufügen → Aus dem Internet abonnieren → Link einfügen.

Link ersetzen

Falls der Link in falsche Hände geraten ist: Ein neuer Link macht den alten sofort ungültig. Danach musst du das Abo auf deinen Geräten neu einrichten.
